# Project: Implementacion-y-comparacion-de-algoritmos

## Overview
This project is dedicated to the implementation and comparison of various algorithms, focusing on performance benchmarking, complexity analysis, and correctness verification. Currently, it features an implementation of the **K-Means Clustering** algorithm applied to the classic Iris dataset.

## Project Structure
- `algorithm.py`: Main module containing the implementation of algorithms. Currently includes:
    - **K-Means Clustering**: Implementation using `scikit-learn`, featuring data scaling, the Elbow method for optimal $K$ selection, and visualization.
- `elbow_method.png`: Visualization generated by `algorithm.py` showing the within-cluster sum of squares (WCSS) to determine the optimal number of clusters.
- `kmeans_iris_2d.png`: 2D scatter plot visualization of the Iris dataset clusters and their centroids.
- `.venv/`: Python virtual environment for managing project-specific dependencies.

## Building and Running
### Prerequisites
- Python 3.13 (as detected in the virtual environment).

### Setting Up the Environment
1.  **Activate the Virtual Environment:**
    - On Windows: `.venv\Scripts\activate`
    - On macOS/Linux: `source .venv/bin/activate`
2.  **Install Dependencies:**
    The project requires the following libraries:
    ```bash
    pip install pandas numpy matplotlib seaborn scikit-learn
    ```

### Running Algorithms
- Execute the current implementation (K-Means on Iris):
    ```bash
    python algorithm.py
    ```
    This will print metrics (Silhouette Score, Contingency Matrix) to the console and update the `.png` visualization files.

## Development Conventions
- **Language**: Python 3.x.
- **Code Style**: Adhere to PEP 8 standards.
- **Benchmarking**: Use `timeit` or similar tools for performance comparisons.
- **Documentation**: Use docstrings for all functions, explaining purpose, time complexity ($O$), and space complexity.
- **Testing**: Implement unit tests (using `unittest` or `pytest`) for algorithm verification.
